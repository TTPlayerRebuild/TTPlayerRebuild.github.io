### 版本来源

- 社区版默认参考值 `2026.10.10` 来自本次已核对的本地生成文件
  `rebuild/build/generated/ttplayer/build_version.h`，不是网站部署日期。
- 展开“预览版本与完整文字”，可填写实际社区版日期版本，或选择原版 5.7.9 / 5.0.1。
  默认值不是“自动获取最新版”；参考构建变化时需维护 `DEFAULT_BUILD_VERSION`。
- XML 根节点的 `version` 用于配置版本记录/迁移，不可靠地代表当前运行的程序版本。
  网站不据此覆盖预览版本，也不把预览版本写回 XML。
- 所选原版版本只改变文字规则；外观仍为用户指定的 5.7.9 默认皮肤。

## 长名称处理

默认皮肤的信息矩形为 `(17,35)-(190,49)`，宽 173，Tahoma 13 像素。
此前只裁切文字，后半段始终无法看到。原版 `004091B4` / `0040939C` 测量文字，
`004092FC` 开启 40 ms 定时器，`0040989E` 每次移动 1 像素，首尾各停留 25 次计时后反向。
社区版 `StartSkinInfoItem` / `OnSkinInfoScrollTimer` 沿用该规则。

网站现使用相同逻辑步长和停留时间：固定 SVG 裁切区，只移动内部文字。名称、程序类型或版本
变更时重新测量、回到起点，不缩小字号或扩大皮肤。

- 原版关于署名保持单行，超出可用区域时裁切。
- 社区版“社区版”保持可见，“献给 xxx”在余下空间单行省略。
- 折叠区域可查看完整标题和署名，署名保留完整悬停提示。
- 遵守系统减少动态效果偏好：停用滚动，但完整文字仍可查看。
- 页面隐藏时停表，恢复可见时从起点重新开始，避免后台积累计时。

浏览器字体回退、抗锯齿和计时调度与 GDI 有差异；这里恢复文字及滚动规则，不宣称所有系统逐像素相同。

### 分析得到的实施路径

1. **接收文件。** 左侧预览提供拖放、选择 SKN 和恢复默认皮肤。读取本地字节，以 ZIP 签名
   校验，不只看后缀。与右侧 XML 拖放分开。参考 [MDN 文件拖放](https://developer.mozilla.org/en-US/docs/Web/API/HTML_Drag_and_Drop_API/File_drag_and_drop)。
2. **读取 ZIP。** 参考 `rebuild/src/skin/skin_package.cpp` 的 stored/deflate、资源名大小写兼容、
   条目/本地头检查。可用 Worker 解压所需条目；`DecompressionStream('deflate-raw')` 只处理
   压缩数据，不负责 ZIP 目录和 CRC。检测具体格式支持，旧浏览器可用随站点打包的固定版本
   JS 解压实现。参考 [MDN DecompressionStream](https://developer.mozilla.org/en-US/docs/Web/API/DecompressionStream/DecompressionStream)。
3. **解析旧语法。** 依据原版 `CSkinManager_LoadPackageXml` (`004A747D`) 和
   `CSkinParser_ParsePlayerWindow` (`004A8536`)、社区版 `src/skin/skin.cpp`，只解析支持的
   标签/属性，兼容无引号属性和旧编码；不把皮肤描述插入 HTML。
4. **解码图片。** 兼容调色板、24/32 位 BMP、行对齐、上下方向及透明色；不能将 BMP 保留
   字节一律当作 alpha。其它图像按签名判断，参照 `skin_image.cpp`，不能依赖扩展名。
5. **按皮肤组合。** 从 `player_window image` 取背景，按位置及图条状态绘制按钮、时间、
   进度和音量；读取 info 的位置、字体、字号、颜色、背景和对齐。Canvas 合成静态部分，
   SVG/Canvas 绘制标题，复用版本与滚动逻辑。其它皮肤不能沿用默认的 173 像素宽度。
6. **边界与验收。** 限制压缩体积、实际解压字节、条目数、图像像素数，逐块限制输出；拒绝
   加密包、多义重名、越界路径和外部引用。验证表中皮肤、中文路径、长/空名称、连续拖入、
   损坏包、缺少 info 的皮肤；切换时取消旧任务、释放旧图像。

静态主窗口预览不需运行 EXE/DLL 或上传皮肤。目前实现主窗口；迷你、歌词、
均衡器、列表、动画及完整窗口缩放交互仍需各自适配，不能等同于完整播放器换肤。
拖入只影响网页外观：浏览器文件对象不能确定播放器安装目录，不应自动将其写成 XML 皮肤路径。

## 2026-10-10 SKN 拖放实施

### 模块与当前范围

- `skn-package.js`：ZIP 目录、本地头、CRC32、解压长度检查；方法 0/8；资源名大小写兼容；
  旧语法 token 解析支持无引号/相邻/重复属性、裸 `&`、结束标签后的旧附加文字。
  支持 UTF-8、UTF-16 和 GBK；只接受第 2 版皮肤，不把 XML 当作 HTML 执行。
- `skn-bitmap.js`：BMP 调色板及 1/4/8/16/24/32 位、RGB/bitfields、倒置行和色键透明；
  区分 BMP 保留 alpha 字节与 ICO 的 alpha/AND mask。其它位图按签名识别 PNG/JPEG/GIF；
  ICO 选取接近 16 像素的帧。RLE BMP、非常规 ICO 头等不在当前支持范围。
- `skn-render.js` / `skn-worker.js`：Worker 内解压、解码、Canvas 组合，输出 PNG。
  四态按钮按图条帧的实际尺寸绘制，时间按 12 字符图条显示 `00:00`，进度为起点，
  音量预览固定 10%；辅助窗口按钮使用选中状态。网络/登录按钮不显示。
  图标缺失时使用播放器默认图标，其它可选图片缺失时跳过并记录说明。
- `skn-preview.js`：拖放/选择、恢复默认、加载状态、失败保留、连续切换取消和 Blob URL 回收。
  主图按比例缩小到可用宽度和最多 360 像素高，不放大原始图像；文字使用同一皮肤坐标系。
- `preview.js`：换肤重测信息区宽度、字体与对齐；超长文字从左边缘往返滚动，
  短文字按皮肤左/中/右对齐。没有信息区时隐藏旧文字，完整名称仍可展开查看。

### 大小及运行限制

皮肤包最大 8 MiB、目录最多 1024 项、声明累计解压最大 64 MiB、单项最大 16 MiB、
Skin.xml 最大 512 KiB。流式解压逐块校验实际输出上限，不能先完整解压再限额。
单图每边最多 4096、最多 8M 像素，累计解码最多 16M 像素，单次 Worker 超时 15 秒。
拒绝加密、多卷、ZIP64、重名/大小写冲突、资源重叠、越界路径和 DTD/实体声明。
使用原生解压和 OffscreenCanvas，不增加第三方运行时依赖；缺少这些 API 时报告错误。

### 验证边界

- 177 个本地 SKN 均通过目录/XML/CRC 检查，并在浏览器 Worker 中生成主窗口 PNG。
  此项是加载及绘制完成检查，不是 177 个皮肤逐像素人工对比。
- 默认、PurpleMyth、Classic、Winamp、PurpleMythSE 做了浏览器显示与信息矩形检查，
  包括调色板 BMP、ICO、自定义字体/颜色、右对齐以及 64 字名称。
- 本地浏览器夹具用 File/DataTransfer 分发 drop 事件，验证正常拖入、连续拖入、
  恢复默认取消、损坏包保留以及无信息区；同时通过系统文件选择流程加载真实皮肤。
- 320 像素宽度验证无横向溢出，名称/版本/生成 XML 的原有回归继续通过。
- stored ZIP 及扩展名仍为 `.bmp`、内容分别为 PNG/JPEG/GIF 的背景均通过浏览器绘制检查。
- 边界用例覆盖截断、CRC 损坏、虚假解压长度、加密标记、路径越界、坏 XML、
  调色板/保留 alpha 和图标掩码。测试及样本只留在 `rebuild/tests/website/`。

XML 中的版本、个人名称和其它配置不受换肤影响。加载皮肤不会写入 XML 的皮肤路径。
